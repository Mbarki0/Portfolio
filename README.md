# Portfolio — Mohammed M'BARKI

Portfolio public consacré au génie logiciel, aux API, aux systèmes distribués et à l’IA générative.

Le site est directement publié par GitHub Pages :

https://mbarki0.github.io/Portfolio/

## Structure

- `index.html` : page publique prête à être affichée ;
- `assets/` : styles, scripts, logo MBK, visuels et CV ;
- `.nojekyll` : publication statique directe par GitHub Pages.

Aucune installation ni commande locale n’est nécessaire pour consulter le site.
